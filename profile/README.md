# AustSec

安徽理工大学网络空间安全协会（AustSec）是由学生成员共同建设的网络安全学习与开源协作组织。

我们从基础出发，围绕实践、交流和分享，持续探索网络安全、软件开发与人工智能的交叉方向。

> AustSec 是学生成员自主建设的社团与开源组织，不代表安徽理工大学官方立场。

## 我们关注什么

- **CTF**：Web、Pwn、Reverse、Crypto、Misc 等方向，以赛促学。
- **SRC 与安全研究**：资产梳理、漏洞复现、报告撰写和安全研究流程。
- **Security**：Web 安全、渗透测试、逆向工程、二进制安全与安全开发。
- **AI + Dev**：编程基础、网站与工具开发、AI 应用，以及 AI 与安全的结合。
- **Signal**：比赛信息、学习路线、工具资源、开源项目与行业动态。

## 我们正在建设

我们欢迎成员参与以下工作：

- 开源工具、网站和自动化脚本；
- CTF 题解、学习笔记和安全研究记录；
- 学习路线、资料索引与比赛信息整理；
- 面向新成员的入门内容和协作项目。

所有项目都鼓励清晰的文档、可复现的步骤和负责任的安全披露。

## 参与 AustSec

无论你刚开始了解网络安全，还是已经有自己的研究方向，都欢迎参与交流和建设。你可以：

1. 浏览我们的[组织仓库](https://github.com/Aust-Sec)，了解公开项目；

3. 在公开仓库中阅读文档、提出 Issue 或提交 Pull Request；
4. 加入公开交流群：**894285023**。
